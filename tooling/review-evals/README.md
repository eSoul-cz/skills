# Review eval set

Cases for scoring `esoul-review` and the reviewer agents: one JSON file per revert, hotfix, or incident in `cases/`, plus known-clean changes. References only (repository, SHAs, location, one-sentence defect), never client code or data.

Case format, how to run the eval, and how to score it: [skills/esoul-review/references/evals.md](../../skills/esoul-review/references/evals.md).
