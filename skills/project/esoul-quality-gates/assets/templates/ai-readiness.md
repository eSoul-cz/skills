# AI readiness — {{PROJECT_NAME}}

The rules for robots, sitemap, `llms.txt`, Markdown versions and the preview environment are in the
guideline [public-website.md](project_guidelines/public-website.md); the eSoul skill
`esoul-quality-gates` (`references/ai-readiness.md`) adds the slices, the checker and the launch
gate. This document records how this project meets them. The site generates every machine-readable
output itself from its own data, without external services. Every failing `must` check blocks the
launch unless a confirmed exception below covers it. The work is planned as slices AI-01 to AI-06
(AI-06 for an e-shop only).

## Crawler policy

Default: **everything allowed**, training bots included (GPTBot, ClaudeBot, Google-Extended,
Applebot-Extended, CCBot). A deviation (the client opts out of training) is a confirmed exception in
the table below.
